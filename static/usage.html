LOG ZIP RENAME — Usage Manual
Steps, naming rules, and edge cases.
Back

What to upload

  • Upload one container ZIP (max 200MB).
  • The container should include multiple inner .zip files.
  • Non-zip files inside the container are skipped.

Required inputs

  • Exam, City, Center, Tech (required)
  • Server Number: exactly 2 digits (01..99)
  • Date format: choose DD-MM-YYYY or MM-DD-YYYY

Detection rules

  • Server kind is detected from filename text only:
    • TCMAIN / TCMAINSVR → M
    • TCBACKUP / TCBACKUPSVR → B
  • Any digits in the filename like SVR02/SVR03 are ignored.
  • Server number used in output is always your input (01..99).

Output name format

EXAM_CITY_CENTER_TECH_{M|B}{SERVER_NUMBER}_DATE.zip

Edge cases handled

  • Date not found → uses NO-DATE and continues.
  • Server kind not found → uses U## and continues.
  • Duplicate output names → adds _1, _2, …
  • Corrupt/empty ZIP → returns a clear error.
  • Too many users → queued, then returns 429 if server is busy.

Log file

The output ZIP includes: ULTRA_FAST_ZIP_BATCH_RENAMER_LOG.txt
